# ΓΑΜΟΣ ΑΛΑ ΕΛΛΗΝΙΚΑ — ΦΩΤΟΓΡΑΦΙΑ & ΒΙΝΤΕΟ

Πρώτη λειτουργική έκδοση front-end.

Περιλαμβάνει 4 τύπους μυστηρίου, φόρμες, ημερολόγιο, αποθήκευση στον browser, πλήρη φάκελο, επεξεργασία και διαγραφή.

Η έκδοση αυτή χρησιμοποιεί localStorage του browser. Για μόνιμη αποθήκευση σε πολλές συσκευές θα προστεθεί ξεχωριστό backend/database του συγκεκριμένου project.
